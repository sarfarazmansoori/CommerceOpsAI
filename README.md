# CommerceOps AI

An agentic AI operations assistant for e-commerce businesses.

## Initial capabilities

- Investigate order and shipment exceptions
- Identify inventory issues
- Recommend policy-compliant actions
- Require approval for sensitive operations
- Record decisions and evaluate agent performance

## Technology

- Python
- Amazon Bedrock
- AWS Lambda
- Amazon DynamoDB
- Amazon S3
- AWS IAM
- Amazon CloudWatch
- Docker
- Terraform
- GitHub Actions

## Project status

Initial development and local prototype.
